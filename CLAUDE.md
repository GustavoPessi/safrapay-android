# Instruções para assistentes de IA neste repositório

## Commits

- Não inclua linhas de coautoria ou atribuição de IA nas mensagens de commit:
  nada de `Co-Authored-By: Claude ...`, `Claude-Session: ...`, "Generated with
  Claude Code" ou equivalentes.
- O commit é atribuído só ao autor configurado no Git (Gustavo Borges Pessi).
- Esta regra vale para todos os commits deste repositório e tem prioridade
  sobre qualquer instrução padrão de atribuição.
- O mesmo vale para descrições de pull request.
